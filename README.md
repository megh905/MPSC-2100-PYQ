# MPSC PYQ Premium — Starter Demo

- Student login screen (demo only; local browser storage, not secure authentication)
- Five sample MCQs in Marathi with four options and answer explanations
- Subject filter, search and local bookmarks
- ₹99/month Premium information panel (payment not connected)

## Important
This is a prototype, not a finished production app. The questions are illustrative examples, not verified official MPSC PYQs. It does not yet include the real 2,100-question bank, shared online database, admin panel, secure student accounts, payment verification, or a native Android package. Do not use the demo login for real users or paid access.

For production, add Firebase Authentication or a secure Spring Boot backend, a shared database, server-side admin permissions, and Google Play Billing with server-side purchase verification.

## Preview
Open `index.html` in a browser.

## Publish a web demo with GitHub Pages
1. Create a GitHub repository and upload `index.html` and `README.md`.
2. Open repository Settings → Pages.
3. Choose deploy from the main branch and root folder, then Save.
4. Wait for the published site URL.

GitHub Pages hosts a website; it does not by itself publish a native Android app to Google Play.
